プロジェクト概要
=========================

背景と目的
-------------------------

Laravelの習得を目的として、日常生活で継続的に使える個人向けWebアプリケーションを開発します。
完全プライベートな用途とし、業務用途や現在の仕事に関する機能は対象外とします。

### 現状の課題

- 単純なTodoアプリやブログでは、開発のモチベーションを維持しにくい
- 学習で得た知識を継続的に試せる実用的な題材がない

### 期待される効果

- Laravelを使ったWebアプリケーションの設計から実装・運用までを一通り経験する
- 日常生活で継続的に利用できるアプリケーションを得る

業務概要
-------------------------

### 業務内容

開発対象は、日常生活を支える個人向けツールです。
具体的な機能は未確定であり、候補と段階的な実装計画は[アプリ企画](app_planning.md)にまとめています。

### 利用者

開発者本人1名を想定します。
完全プライベートな用途のため、不特定の利用者や業務利用は対象外です。

### 制約事項

- 業務用途や現在の仕事に関する機能は対象外とする
- 小さく作り、段階的に機能を追加する
- 実用性とLaravelの学習を両立する
