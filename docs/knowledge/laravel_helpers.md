Laravelのグローバルヘルパ関数
=========================

概要
-------------------------

Laravelは、名前空間を書かずに呼べるグローバル関数を多数用意しています。
このファイルでは、このプロジェクトで実際に使える関数をカテゴリ別に整理します。
一覧はインストール済みの`vendor/`配下から抽出したものです。

対象バージョン
-------------------------

このプロジェクトの`laravel/framework`はv13.39.0です。
`vendor/laravel/framework/src/`配下の次の4ファイルから、99件の関数を抽出しています。

| ファイル                             | 役割                   |
| ------------------------------------ | ---------------------- |
| `Illuminate/Collections/helpers.php` | 配列とコレクション     |
| `Illuminate/Foundation/helpers.php`  | アプリケーション全般   |
| `Illuminate/Reflection/helpers.php`  | 遅延インスタンスの生成 |
| `Illuminate/Support/helpers.php`     | 文字列などの補助       |

`dump()`と`dd()`は`vendor/symfony/var-dumper/Resources/functions/dump.php`で定義されています。
上記99件には含まれません。

一覧の再取得方法
-------------------------

バージョンアップで関数が増減したときは、次のコマンドで一覧を取り直します。

```bash
grep -hoP '^\s*function\s+\K\w+' vendor/laravel/framework/src/Illuminate/*/helpers.php | sort -u
```

このコマンドはLaravel本体の4ファイルだけを対象にします。
`dump()`と`dd()`はSymfony側で定義されているため含まれません。
