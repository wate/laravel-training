Laravelモデルの拡張ポイント
=========================

概要
-------------------------

Eloquentモデルには、定義しておくとフレームワークが決まったタイミングで呼ぶメソッドがあります。
このファイルでは、オーバーライドや定義で振る舞いを差し込めるメソッドを整理します。
設定で有効化するのではなく、モデル側にコードを書いて振る舞いを定義します。

ライフサイクル
-------------------------

`Model::bootTraits()`が、モデルが使うトレイトから起動用のメソッドを探して呼びます。

| メソッド                | 呼ばれるタイミング   |
| ----------------------- | -------------------- |
| `booting()`             | モデルの起動前       |
| `booted()`              | モデルの起動後       |
| `boot{Trait名}()`       | モデルの起動時       |
| `initialize{Trait名}()` | インスタンスの生成時 |

`boot{Trait名}`と`initialize{Trait名}`は、`#[Boot]`と`#[Initialize]`属性でも指定できます。

設定値
-------------------------

モデルの設定は、プロパティかメソッドで指定します。
メソッドにすると、実行時に値を変えられます。

| メソッド               | 返すもの               |
| ---------------------- | ---------------------- |
| `getTable()`           | テーブル名             |
| `getKeyName()`         | 主キーの列名           |
| `getKeyType()`         | 主キーの型             |
| `getIncrementing()`    | 主キーの自動採番       |
| `usesTimestamps()`     | タイムスタンプの有無   |
| `getCreatedAtColumn()` | 作成日時の列名         |
| `getUpdatedAtColumn()` | 更新日時の列名         |
| `getConnectionName()`  | 接続名                 |
| `getDateFormat()`      | 日付の保存形式         |
| `getFillable()`        | 一括代入を許可する列   |
| `getGuarded()`         | 一括代入を禁止する列   |
| `getHidden()`          | 配列変換で隠す列       |
| `getVisible()`         | 配列変換に含める列     |
| `getAppends()`         | 配列変換で追加する属性 |
| `getPerPage()`         | ページあたりの件数     |
| `casts()`              | キャストの定義         |

`casts()`はメソッドで定義するキャストです。
プロパティの`$casts`も引き続き使えます。

生成
-------------------------

| メソッド               | 役割                     |
| ---------------------- | ------------------------ |
| `newFactory()`         | 使うファクトリを返す     |
| `newEloquentBuilder()` | 独自のクエリビルダを返す |
| `newCollection()`      | 独自のコレクションを返す |

ルーティング
-------------------------

| メソッド                | 役割                                 |
| ----------------------- | ------------------------------------ |
| `getRouteKeyName()`     | ルートで使うキー列を返す             |
| `resolveRouteBinding()` | ルートパラメータからモデルを解決する |

`getRouteKeyName()`を`slug`にすると、`/posts/{post}`が`slug`で解決されます。

スコープ
-------------------------

`scope{Name}`という名前のメソッドを定義すると、`{name}()`として呼び出せます。
`#[Scope]`属性でも指定できます。

イベント
-------------------------

| メソッド             | 役割                                           |
| -------------------- | ---------------------------------------------- |
| `dispatchesEvents()` | モデルイベントに割り当てるイベントクラスを返す |

オブザーバは`created`、`updated`、`deleted`などのメソッド名で呼ばれます。
オブザーバは`#[ObservedBy]`属性でも登録できます。

プルーニング
-------------------------

| メソッド     | 役割                       |
| ------------ | -------------------------- |
| `prunable()` | 削除対象を絞るクエリを返す |

注意点
-------------------------

- メソッド名を変えるとフックが呼ばれなくなります
- 戻り値の型や意味を変えると、フレームワークの動作が壊れます
- プロパティで足りる設定は、メソッドにしません
