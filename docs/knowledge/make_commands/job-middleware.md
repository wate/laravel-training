Laravelのmake:job-middleware
============================

概要
-------------------------

`make:job-middleware`はジョブミドルウェアクラスを生成します。
ジョブミドルウェアは、ジョブの`handle()`実行前後に挟む横断的な処理です。

ジョブミドルウェアとは
-------------------------

HTTPミドルウェアがリクエストの前後で動くように、ジョブミドルウェアはジョブの前後で動きます。
すべてのジョブに必要なものではなく、レート制限や重複防止が必要なときに使います。

代表的な用途は次のとおりです。

- 外部APIのレート制限
- 同じジョブの重複実行防止
- 例外多発時のリトライ抑制
- バッチキャンセル時の残りジョブ停止
- テナント情報の設定

キュー接続や配送サービスを切り替える仕組みではありません。
キュー接続は`onConnection()`や`onQueue()`、配送サービスは設定やサービス委譲で切り替えます。

生成物と生成先
-------------------------

| 生成物             | 生成先                           |
| ------------------ | -------------------------------- |
| ジョブミドルウェア | `app/Jobs/Middleware/<Name>.php` |

オプション
-------------------------

| オプション | 短縮 | 用途                       |
| ---------- | ---- | -------------------------- |
| `--force`  | `-f` | 同名ファイルを上書きします |

生成内容
-------------------------

`php artisan make:job-middleware RateLimited`は次の形を生成します。

```php
class RateLimited
{
    public function handle(object $job, Closure $next): void
    {
        $next($job);
    }
}
```

`$next($job)`を呼ぶとジョブ本体が実行されます。
呼ばずに戻ると、ジョブは実行されません。

標準のジョブミドルウェア
-------------------------

| クラス                 | 用途                                           |
| ---------------------- | ---------------------------------------------- |
| `RateLimited`          | 名前付きレートリミッターで実行回数を制限します |
| `WithoutOverlapping`   | 同じジョブの重複実行を防ぎます                 |
| `ThrottlesExceptions`  | 例外が続く場合に再試行を遅らせます             |
| `SkipIfBatchCancelled` | キャンセルされたバッチの残りをスキップします   |

`RateLimited`を使う場合は、`AppServiceProvider`で名前付きリミッターを定義します。

```php
RateLimiter::for('emails', function (object $job) {
    return Limit::perMinute(100);
});
```

ジョブへの適用
-------------------------

ジョブクラスの`middleware()`で指定します。

```php
public function middleware(): array
{
    return [
        new RateLimited('emails'),
        (new WithoutOverlapping($this->user->id))->expireAfter(600),
    ];
}
```

`WithoutOverlapping`のキーには、ジョブやユーザーごとの一意な値を使います。

使いどころ
-------------------------

- 一斉配信で外部APIの上限を守る
- 同じユーザーの処理を同時に走らせない
- 例外が続く外部APIを一時的に抑える
- バッチキャンセル時に残りを止める

注意点
-------------------------

- ジョブミドルウェアは必須ではありません
- 単純な前後処理は`handle()`に直接書けます
- `RateLimited`はキャッシュとリミッター定義が必要です
- `WithoutOverlapping`はキャッシュロックを使います
- キュー接続の切り替えには使えません
