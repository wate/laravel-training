Laravelのmake:view
=========================

概要
-------------------------

`make:view`はBladeビューの雛形を生成します。
既定の生成先は`resources/views`です。

生成物と生成先
-------------------------

| 生成物      | 生成先                                  |
| ----------- | --------------------------------------- |
| Bladeビュー | `resources/views/posts/index.blade.php` |

名前に`.`や`/`を使うとディレクトリに分かれます。

- `make:view posts.index`は`resources/views/posts/index.blade.php`を生成します
- `make:view posts/index`も同じファイルを生成します

オプション
-------------------------

| オプション                | 短縮 | 用途                                                        |
| ------------------------- | ---- | ----------------------------------------------------------- |
| `--extension[=EXTENSION]` | なし | 生成するファイルの拡張子を指定します。既定は`blade.php`です |
| `--force`                 | `-f` | 同名ファイルを上書きします                                  |
| `--test`                  | なし | 既定の形式のテストを生成します                              |
| `--pest`                  | なし | Pestテストを生成します                                      |
| `--phpunit`               | なし | PHPUnitテストを生成します                                   |

生成内容
-------------------------

`php artisan make:view posts.index`は次の形を生成します。

```blade
<div>
    <!-- ランダムな引用文 -->
</div>
```

コメントにはランダムな引用文が入ります。
ビューの名前は入りません。

テスト
-------------------------

`--phpunit`を付けるとビューのテストも生成されます。
テストの名前空間はビュー名から組み立てられます。
単純な名前の例では`tests/Feature/View/WelcomeTest.php`になります。

使いどころ
-------------------------

- 画面の雛形を先に作るとき
- コンポーネント化する前に通常のBladeビューを作るとき
- 画面のテストを同時に用意するとき

注意点
-------------------------

- `--extension=html`のようにBlade以外の拡張子も指定できます。Bladeとして使う場合は既定のままにします
- 同名ファイルがある場合は`--force`を付けないとエラーになります
