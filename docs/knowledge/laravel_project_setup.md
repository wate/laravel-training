Laravelプロジェクトのセットアップ
=================================

概要
-------------------------

プロジェクトの技術スタックを決めたうえで、`composer create-project`でスケルトンを作成し、構成を調整する手順をまとめます。

技術スタックの決定
-------------------------

スケルトンを作成する前に、次の項目を決めます。
判断材料は[docs/app_planning.md](../app_planning.md)の「今後決めること」を参照してください。

- アプリの利用目的
- Laravelで習得したい範囲
- フロントエンドの構成

スケルトンの作成
-------------------------

```bash
composer create-project laravel/laravel example-app
cd example-app
```

技術スタックに応じた調整
-------------------------

既定の構成のままでは使い勝手が悪いため、決めた技術スタックに合わせて調整します。

### 不要な部分の削除

- 使わないサンプルコードや既定のファイルを削除します

### 依存関係の調整

- `composer.json`: 採用しないパッケージを削除し、必要なパッケージを追加します
- `package.json`: 採用しないフロントエンドの依存を削除し、必要な依存を追加します

### ローカル開発環境

既定の構成はシンプルで、データベースはSQLiteを使用します。
そのままでは実際の開発に合わないケースが多いため、必要に応じて環境を用意します。
構築手順は[ローカル開発環境](../local_environment.md)を参照してください。

### 設定ファイル

- `.editorconfig`: 文字コード、改行コード、インデントを統一します
- `.markdownlint.yml`: Markdownの規約を定義します
- `.npmrc`: `ignore-scripts`と`audit`を設定します

### エージェント環境

- `.github/`: Copilot向けの設定、フック、プロセス、インストラクションを配置します
- `.agents/skills`: `skills-lock.json`からスキルを復元します
- `.ticket/`: MD-Ticketを導入します

### ドキュメント

- `docs/`: プロジェクトブリーフ、技術スタック、ディレクトリ構造、コーディング規約、ナレッジを配置します
- `AGENTS.md`: エージェント向けガイドラインを作成します
- `README.md`: プロジェクト概要とセットアップ手順に置き換えます

### Git管理

- `.gitignore`: `.agents/`と`.github/feedback/`を追加します

動作確認
-------------------------

ローカル開発環境の構築と動作確認の手順は[ローカル開発環境](../local_environment.md)を参照してください。
