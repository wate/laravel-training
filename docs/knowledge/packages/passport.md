Laravel Passport
=========================

概要
-------------------------

Laravel PassportはOAuth2サーバーの完全な実装です。
League OAuth2 serverを基に、アクセストークンと認可の仕組みを提供します。

向いている場面
-------------------------

- 自社APIをOAuth2で第三者に公開する
- 認可コードグラントやPKCEが必要な場合に使う
- デバイスコードグラントやクライアントクレデンシャルが必要な場合に使う

認可コード、PKCE、デバイスコード、クライアントクレデンシャルに対応します。
パスワードグラントと暗黙的グラントは非推奨です。

Sanctumとの使い分け
-------------------------

OAuth2が必須の場合だけPassportを使います。
SPA、モバイルアプリ、単純なAPIトークンはSanctumで足ります。
パーソナルアクセストークンだけが必要な場合もSanctumを選びます。

導入
-------------------------

```
php artisan install:api --passport
```

このコマンドはマイグレーションの実行と暗号化キーの生成を行います。
`User`モデルに`HasApiTokens`トレイトと`OAuthenticatable`インターフェースを追加します。
`config/auth.php`の`api`ガードは`passport`ドライバに設定します。

主な機能
-------------------------

- 認可コードグラントとPKCE
- デバイス認可グラント
- クライアントクレデンシャルグラント
- パーソナルアクセストークン
- スコープによる権限管理
- アクセストークンとリフレッシュトークンの有効期限設定

運用
-------------------------

鍵は`php artisan passport:keys`で生成します。
本番環境では環境変数`PASSPORT_PRIVATE_KEY`と`PASSPORT_PUBLIC_KEY`で読み込めます。
不要なトークンは`php artisan passport:purge`で削除できます。
既定のアクセストークンは1年間有効です。

このプロジェクトでの利用
-------------------------

未使用です。
第三者にAPIを公開する要件が出た場合に検討します。
