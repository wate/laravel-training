Laravel Fortify
=========================

概要
-------------------------

Laravel Fortifyはフロントエンドに依存しない認証バックエンドです。
ログイン、ユーザー登録、パスワードリセット、メール確認などのルートとコントローラを提供します。
画面は提供しないため、UIはアプリケーション側で用意します。

向いている場面
-------------------------

- スターターキットを使わず、自前のUIで認証を実装する
- 2要素認証やパスキーをバックエンド機能として追加する
- BladeでもJavaScriptのSPAでも同じ認証APIを使いたい

後述のスターターキットはFortifyを内部で利用しています。
スターターキットを使う場合はFortifyを別途導入する必要はありません。

主な機能
-------------------------

- ログイン、ユーザー登録、パスワードリセット、メール確認
- 2要素認証(TOTP)とリカバリーコード
- パスキー(WebAuthn)
- パスワード確認
- ログイン試行のスロットリング
- 認証処理のパイプラインカスタマイズ

導入
-------------------------

```
composer require laravel/fortify
php artisan fortify:install
php artisan migrate
```

`fortify:install`は`app/Actions`、`FortifyServiceProvider`、設定ファイル、マイグレーションを生成します。

設定
-------------------------

- `config/fortify.php`の`features`で有効化する機能を選びます
- 画面を自前で持つ場合は`views`を`false`にします
- ビューの指定は`Fortify::loginView()`などで行います
- 認証処理は`app/Actions/Fortify`配下のアクションでカスタマイズします

Sanctumとの関係
-------------------------

Fortifyは認証の入口を担当し、SanctumはトークンとSPAのセッション認証を担当します。
両者は競合せず、同じアプリケーションで併用できます。
SPAで利用する場合は`web`ガードとSanctumを組み合わせます。

このプロジェクトでの利用
-------------------------

未使用です。
AdminLTEのログイン画面に認証機能を追加する場合、バックエンドとしてFortifyを利用できます。
