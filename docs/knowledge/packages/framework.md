Laravel Framework
=========================

概要
-------------------------

Laravel FrameworkはLaravelの本体パッケージです。
ルーティング、Eloquent ORM、Blade、キュー、認証、バリデーションなどを含みます。
スケルトンの`require`に含まれ、`composer create-project`で自動的に導入されます。

主な機能
-------------------------

- ルーティングとミドルウェア
- Eloquent ORMとマイグレーション
- Bladeテンプレート
- 認証と認可
- キュー、イベント、スケジューラ
- バリデーションとテスト支援

バージョン
-------------------------

このプロジェクトは`^13.17`を利用しています。
バージョンは`composer.json`で管理します。
