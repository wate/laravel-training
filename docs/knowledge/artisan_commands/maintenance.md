Laravelのメンテナンスモード
=========================

概要
-------------------------

`down`はアプリケーションをメンテナンスモードに切り替え、`up`は解除します。
メンテナンスモード中は、既定でHTTPステータス503を返します。
デプロイ中の一時停止や、データベース変更中のアクセス制御に使います。

主なコマンド
-------------------------

| コマンド           | 用途                           |
| ------------------ | ------------------------------ |
| `php artisan down` | メンテナンスモードに入ります   |
| `php artisan up`   | メンテナンスモードを解除します |

主なオプション
-------------------------

`down`の主なオプションです。

- `--redirect[=REDIRECT]`: リダイレクト先のパスを指定します
- `--render[=RENDER]`: メンテナンス画面に表示するビューを指定します
- `--retry[=RETRY]`: 再試行までの秒数または日時を指定します
- `--refresh[=REFRESH]`: ブラウザを再読み込みするまでの秒数を指定します
- `--secret[=SECRET]`: メンテナンスモードを回避する秘密の文字列を指定します
- `--with-secret`: 回避用の秘密の文字列をランダムに生成します
- `--status[=STATUS]`: メンテナンス応答のHTTPステータスを指定します

使用例
-------------------------

### メンテナンスモードに入る

```bash
php artisan down
```

再試行までの時間を60秒に指定する場合は`--retry=60`を使います。

```bash
php artisan down --retry=60
```

### 秘密の文字列で回避する

```bash
php artisan down --secret="my-secret"
```

メンテナンス中に`https://example.com/my-secret`へアクセスすると、cookieが設定されメンテナンスモードを回避できます。

### リダイレクト先を指定する

```bash
php artisan down --redirect=/maintenance
```

### メンテナンスモードを解除する

```bash
php artisan up
```

注意点
-------------------------

- メンテナンスモード中は、既定でHTTPステータス503を返します
- `--secret`の文字列は外部へ漏らさず、回避用URLを共有しないようにします
- `--render`で指定するビューは事前に用意します
- `--retry`は`Retry-After`ヘッダー、`--refresh`は`Refresh`ヘッダーに使われます
- `up`を実行するまでメンテナンスモードは解除されません
