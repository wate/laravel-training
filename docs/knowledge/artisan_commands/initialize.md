Laravelの初期化コマンド
=========================

概要
-------------------------

`php artisan key:generate`は`APP_KEY`を生成し、環境ファイルへ書き込みます。
`APP_KEY`は暗号化とセッションの保護に使われます。
初期構築では、キー生成に加えてDBのマイグレーション、シーダー、ストレージリンクの作成を行います。

主なコマンド
-------------------------

| コマンド                   | 用途                                               |
| -------------------------- | -------------------------------------------------- |
| `php artisan key:generate` | `APP_KEY`を生成して`.env`へ書き込みます            |
| `php artisan migrate`      | 未適用のマイグレーションを実行します               |
| `php artisan db:seed`      | シーダーを実行して初期データを投入します           |
| `php artisan storage:link` | `public/storage`へのシンボリックリンクを作成します |

主なオプション
-------------------------

`key:generate`の主なオプションです。

| オプション    | 用途                                     |
| ------------- | ---------------------------------------- |
| `--show`      | キーを表示し、環境ファイルを変更しません |
| `--force`     | 本番環境でも確認なしで実行します         |
| `--env[=ENV]` | 対象の環境を指定します                   |

使用例
-------------------------

### 初回セットアップ

```bash
php artisan key:generate
php artisan migrate
php artisan db:seed
php artisan storage:link
```

`db:seed`は初期データが必要な場合だけ実行します。
`storage:link`は公開ストレージを使う場合だけ実行します。

### キーの確認

`--show`は環境ファイルを変更せず、生成したキーだけを表示します。
CIや本番環境の環境変数へ設定する場合に使います。

```bash
php artisan key:generate --show
```

### 本番環境での実行

本番環境で`key:generate`を実行する場合は`--force`が必要です。
既存の`APP_KEY`を変更すると、暗号化済みデータやセッションが読めなくなります。

```bash
php artisan key:generate --force
```

注意点
-------------------------

- 既存の`APP_KEY`を変更すると、暗号化済みデータとセッションが読めなくなります
- 本番環境で`key:generate --force`を実行する前に、既存キーのバックアップと影響範囲を確認します
- `APP_KEY`は秘密情報のため、リポジトリやドキュメントへ記載しません
- 本番環境で`migrate`を実行する場合は`--force`が必要です
- `storage:link`はファイルを公開する場合だけ実行します
