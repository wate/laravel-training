Laravelの環境情報確認
=========================

概要
-------------------------

`about`は、アプリケーションの環境、キャッシュ、ドライバー、ストレージの概要を表示します。
環境差異の確認や、設定不備の切り分けに使います。
表示するセクションは`--only`で絞り込めます。

主なコマンド
-------------------------

| コマンド                               | 用途                     |
| -------------------------------------- | ------------------------ |
| `php artisan about`                    | 概要をまとめて表示します |
| `php artisan about --only=environment` | 環境情報だけを表示します |
| `php artisan about --json`             | JSONで出力します         |

主なオプション
-------------------------

- `--only[=ONLY]`: 表示するセクションを指定します
- `--json`: 情報をJSONで出力します

指定できるセクションは`environment`、`cache`、`drivers`、`storage`です。

使用例
-------------------------

### 概要を表示する

```bash
php artisan about
```

### 環境情報だけを表示する

```bash
php artisan about --only=environment
```

### キャッシュ情報だけを表示する

```bash
php artisan about --only=cache
```

### JSONで出力する

```bash
php artisan about --json
```

注意点
-------------------------

- 出力には環境変数や設定値が含まれる場合があります。共有前に内容を確認します
- `--only`に指定できるセクションはLaravelのバージョンで変わる場合があります
- `about`は情報を表示するだけで、設定やキャッシュを変更しません
- キャッシュの生成と削除は`optimize.md`を参照してください
