Laravelのストレージリンクコマンド
=========================

概要
-------------------------

`storage:link`は、公開ディレクトリから`storage/app/public`へシンボリックリンクを作成します。
`storage:unlink`は作成したシンボリックリンクを削除します。
公開ストレージを使ってファイルを配信する場合に使います。

主なコマンド
-------------------------

| コマンド                     | 用途                                               |
| ---------------------------- | -------------------------------------------------- |
| `php artisan storage:link`   | `public/storage`へのシンボリックリンクを作成します |
| `php artisan storage:unlink` | 作成済みのシンボリックリンクを削除します           |

主なオプション
-------------------------

`storage:link`の主なオプションです。

- `--relative`: 相対パスでシンボリックリンクを作成します
- `--force`: 既存のシンボリックリンクを再作成します

`storage:unlink`に専用のオプションはありません。

使用例
-------------------------

### シンボリックリンクを作成する

```bash
php artisan storage:link
```

相対パスで作成する場合は`--relative`を付けます。

```bash
php artisan storage:link --relative
```

既存のリンクを作り直す場合は`--force`を付けます。

```bash
php artisan storage:link --force
```

### シンボリックリンクを削除する

```bash
php artisan storage:unlink
```

注意点
-------------------------

- 公開ストレージを使わない場合は実行する必要はありません
- 既存のリンクを作り直す場合は`--force`を使います
- `--relative`はデプロイ先のディレクトリ構成に合わせて使います
- `storage:unlink`はシンボリックリンクだけを削除し、実体ファイルは残します
- シンボリックリンクの作成にはファイルシステムの権限が必要です
