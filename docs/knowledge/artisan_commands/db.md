LaravelのDB操作コマンド
=========================

概要
-------------------------

`db`系のコマンドは、データベースへの接続、シーダーの実行、テーブル定義の確認に使います。
`db`は接続先DBのCLIセッションを開始します。
`db:seed`はシーダーを実行し、`db:show`と`db:table`はDBとテーブルの情報を表示します。
このページは主なdbコマンドを扱い、すべてを網羅していません。
全コマンドは`php artisan list db`で確認してください。

主なコマンド
-------------------------

| コマンド                     | 用途                                             |
| ---------------------------- | ------------------------------------------------ |
| `php artisan db`             | 接続先DBのCLIセッションを開始します              |
| `php artisan db:seed`        | シーダーを実行して初期データを投入します         |
| `php artisan db:show`        | 接続先DBの情報とテーブル一覧を表示します         |
| `php artisan db:table users` | 指定したテーブルの定義とインデックスを表示します |

主なオプション
-------------------------

### db

| オプション   | 用途                             |
| ------------ | -------------------------------- |
| `connection` | 使用するDB接続を引数で指定します |
| `--read`     | 読み取り接続へ接続します         |
| `--write`    | 書き込み接続へ接続します         |
| `--pooled`   | プールされた接続へ接続します     |

### db:seed

| オプション              | 用途                                       |
| ----------------------- | ------------------------------------------ |
| `class`                 | ルートシーダーのクラス名を引数で指定します |
| `--class[=CLASS]`       | ルートシーダーのクラス名を指定します       |
| `--database[=DATABASE]` | シーダーを実行するDB接続を指定します       |
| `--force`               | 本番環境でも確認なしで実行します           |

`--class`を省略すると`Database\Seeders\DatabaseSeeder`を実行します。

### db:show

| オプション              | 用途                           |
| ----------------------- | ------------------------------ |
| `--database[=DATABASE]` | 対象のDB接続を指定します       |
| `--json`                | 情報をJSONで出力します         |
| `--counts`              | テーブルごとの行数を表示します |
| `--views`               | ビューを表示します             |
| `--types`               | ユーザー定義型を表示します     |

`--counts`と`--views`は大きなDBでは時間がかかります。

### db:table

| オプション              | 用途                         |
| ----------------------- | ---------------------------- |
| `table`                 | 対象のテーブル名を指定します |
| `--database[=DATABASE]` | 対象のDB接続を指定します     |
| `--json`                | 情報をJSONで出力します       |

使用例
-------------------------

### DBのCLIセッションを開始する

```bash
php artisan db
```

接続名を指定する場合は引数に渡します。

```bash
php artisan db mysql
```

### シーダーを実行する

```bash
php artisan db:seed
```

特定のシーダーだけを実行する場合は`--class`を指定します。

```bash
php artisan db:seed --class=UserSeeder
```

### DBとテーブルの情報を表示する

```bash
php artisan db:show
php artisan db:show --counts
php artisan db:table users
```

注意点
-------------------------

- `db:seed`を繰り返すとデータが重複する場合があります
- 繰り返し実行する場合は冪等なシーダーを作成します
- 開発環境でDBを作り直す場合は`migrate:fresh --seed`を使います
- 本番環境で`db:seed`を実行する場合は`--force`が必要です
- `db:show --counts`と`--views`は大きなDBでは時間がかかります
- `db`の接続情報は`.env`で管理し、認証情報をドキュメントへ記載しません
